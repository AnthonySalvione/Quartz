# Universal Shortcuts

## Text Navigation

| Shortcut               | What it does                                    | Why it matters                                |
| ---------------------- | ----------------------------------------------- | --------------------------------------------- |
| `Ctrl + ← / →`         | Move one **word** at a time                     | Huge improvement over tapping through letters |
| `Ctrl + Shift + ← / →` | Select whole words                              | Probably one of the most useful for you       |
| `Ctrl + Backspace`     | Delete previous word                            | Much faster editing                           |
| `Ctrl + Delete`        | Delete next word                                | Same, forward                                 |
| `Home`                 | Beginning of line                               |                                               |
| `End`                  | End of line                                     |                                               |
| `Shift + Home`         | Select to beginning of line                     |                                               |
| `Shift + End`          | Select to end of line                           |                                               |
| `Ctrl + Home`          | Top of document                                 | Excellent in long Obsidian files              |
| `Ctrl + End`           | Bottom of document                              |                                               |
| `Shift + ↑ / ↓`        | Extend selection by line                        |                                               |
| `Ctrl + Shift + ↑ / ↓` | Select larger chunks/paragraphs in many editors | App-dependent                                 |
| `Ctrl + A`             | Select everything                               |                                               |
| `Ctrl + Z`             | Undo                                            |                                               |
| `Ctrl + Y`             | Redo                                            |                                               |
| `Ctrl + F`             | Find in current file/page                       | Essential                                     |
## Navigating Tabs and Windows

| Shortcut             | Action                     |
| -------------------- | -------------------------- |
| `Alt + Tab`          | Switch between apps        |
| `Alt + Shift + Tab`  | Switch backward            |
| `Win + Tab`          | See all windows + desktops |
| `Ctrl + Tab`         | Next tab                   |
| `Ctrl + Shift + Tab` | Previous tab               |
| `Ctrl + 1`           | First tab                  |
| `Ctrl + 2`           | Second tab                 |
| `Ctrl + 3`           | Third tab                  |
| etc.                 |                            |
| `Ctrl + 9`           | Last tab                   |
| `Ctrl + W`           | Close current tab          |
| `Ctrl + Shift + T`   | Reopen closed tab          |
| `Alt + ←`            | Back                       |
| `Alt + →`            | Forward                    |
## Window Snapping—**EXTREMLY HELPFUL**

To open Windows' Snap Layouts: *Win + Z*

Quick ways to change layout:
* `Win + ⇐` — snap left
* `Win + ⇒` — snap right
* `Win + ↑` — maximize
* `Win + ↓` — restore/minimize

## Virtual Desktops

`Win + Ctrl + D` — Creates another virtual desktop.
`Win + Ctrl + ⇐ / ⇒` — Switches between desktops instantly.
`Win + Ctrl + F4` — Closes the current virtual desktop.

## Useful shortcuts

**`Win + V`** — opens **Clipboard History**.
**`Win + Shift + S`** — Screenshot/snipping tool.

# Obsidian Shortcuts

## Most useful commands

`Ctrl + O` — Quick Switcher
> Instead of clicking the sidebar ⇒ folder ⇒ folder ⇒ find file ⇒ click file.

`Ctrl + Shift + F` — Search the entire vault
> When you need to look for certain phrases or references across the entire vault.

**`Alt + ←`** — go back  
**`Alt + →`** — go forward
> When following links, instead of manually pressing the back arrow.

## Navigating tabs

`Ctrl + click a link` — To open another tab
`Ctrl + W` — Close that tab when you are finished.

**`Ctrl + Tab`** → next tab
**`Ctrl + Shift + Tab`** → previous tab
**`Ctrl + W`** → close current tab
